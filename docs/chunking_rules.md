# Chunk 切分规则

## JD 类资料

按结构切分：
1. 岗位基本信息
2. 岗位职责
3. 任职要求
4. 加分项
5. 技术关键词
6. 产品关键词

不要把一个长 JD 直接切成固定字数片段。

## AI 知识类资料

按概念切分：
1. 概念定义
2. 产品经理视角
3. 技术流程
4. 面试表达
5. 项目应用
6. 常见误区

## 能力模型类资料

按能力项切分：
1. 能力定义
2. L1-L5 等级
3. 诊断规则
4. 提升建议
5. 对应岗位

## 项目案例类资料

按项目结构切分：
1. 项目背景
2. 目标用户
3. 用户痛点
4. 解决方案
5. 核心功能
6. AI 能力
7. 指标评估
8. 简历表达
9. 面试追问

## 面试题类资料

一题一 chunk：

问题 + 考察点 + 回答框架 + 示例回答 + 追问 + 错误提醒

## 简历模板类资料

一个模板一条 chunk：

模板名称 + 适用项目 + 表达结构 + 示例 bullet + 使用注意事项
